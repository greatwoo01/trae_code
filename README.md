# trae_code

记录信息学奥赛（OI）编程题的解题过程：题意、思路、复杂度、代码与易错点。

## 仓库结构

```text
trae_code/
├── README.md              # 目录索引与解题统计
├── problems/              # 题解文档，按题目来源分类
│   ├── luogu/             # 洛谷，如 P1001-a-plus-b.md
│   ├── codeforces/        # Codeforces，如 1904a-forked.md
│   └── usaco/             # USACO
├── templates/
│   └── solution.md        # 题解模板，新题解从这里复制
└── code/                  # 可运行的 AC 代码（可选）
    └── luogu/P1001.cpp
```

## 如何添加一篇题解

1. 复制 `templates/solution.md` 到对应来源目录，按 `编号-题名.md` 命名。
2. 填写题意、思路、复杂度、代码和易错点。
3. AC 代码可单独放入 `code/<来源>/` 目录，题解中保留核心代码即可。
4. 在下方索引表追加一行，并更新统计。
