# [bas_3451] 【例82.1】不吉利日期

- **日期**：2026-11-11
- **难度**：4
- **算法标签**：枚举、模拟、前缀和
- **题目链接**：https://bas.ssoier.cn/problem_show.php?pid=3451
- **状态**：AC

## 题意简述

在国外，每月的 13 号和每周的星期五都被认为不吉利。已知某年 1 月 1 日是星期 $w$（$w=1..7$，依次对应周一到周日），且该年不是闰年（2 月按 28 天算）。要求找出这一年中所有「13 号恰好是星期五」的月份，按月份从小到大逐行输出。

- 输入：一行一个整数 $w$。
- 输出：若干行，每行一个满足条件的月份编号。
- 样例：输入 `7`（1 月 1 日是周日），输出 `1` 和 `10`，即 1 月 13 日、10 月 13 日是星期五。

## 思路分析

日历题的通用套路：**把日期换算成「距某个已知星期几的天数差」，再用模 7 运算求星期**。

设某个月 1 号是当年的第 $d$ 天（1 月 1 日记为 $d=0$），则：

- 该月 13 号是当年的第 $d+12$ 天；
- 由于星期按 7 循环，13 号的星期为

$$
\left(w - 1 + d + 12\right) \bmod 7 + 1
$$

其中 $w-1$ 是把「1..7 表示周一到周日」转成「0..6 偏移量」，最后 $+1$ 再转回 1..7。星期五对应数值 5。

代码只需维护一个 $d$，按月份顺序累加各月天数即可，无需真的按天模拟：

1. 用数组存下平年每个月的天数 `{31,28,31,30,31,30,31,31,30,31,30,31}`；
2. 令 `d = 0`，从 1 月到 12 月遍历；
3. 用上面的公式计算该月 13 号的星期，等于 5 就输出月份；
4. 把本月天数累加到 `d` 上，进入下个月。

## 复杂度

- 时间：$O(12)$，即 $O(1)$，与输入无关。
- 空间：$O(1)$，仅一个长度 12 的天数数组和常数个变量。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int w;
    cin >> w;                       // 1=周一, 2=周二, ..., 7=周日

    const int days[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

    int d = 0;                      // 本月 1 日是当年的第几天（1 月 1 日记为 0）
    for (int m = 1; m <= 12; ++m) {
        int weekday = (w - 1 + d + 12) % 7 + 1;   // 该月 13 号是星期几
        if (weekday == 5) {
            cout << m << '\n';
        }
        d += days[m - 1];           // 累加本月天数，得到下月 1 号的偏移
    }
    return 0;
}
```

## 易错点 / 总结

- **星期编号方向**：题目 $w=1$ 是周一，若按「周日=1」的习惯计算会整体错位。统一用 $(w-1+\text{偏移}) \bmod 7 + 1$ 更不容易出错。
- **偏移量基准**：1 月 1 日的偏移是 0，所以 13 号要加 12 而不是 13；这是本题最常见的 off-by-one。
- **闰年**：题目保证不是闰年，2 月固定 28 天；若题目不保证，需要先判断闰年再修改 2 月天数。
- **取模位置**：必须在加完所有偏移后再统一取模，先取模再相加容易遗漏进位。
- **输出格式**：每行一个月份，不要在行末多输出空格，否则部分 OJ 会判格式错误。
- **本题收获**：日历问题不需要逐日枚举，把「日期 → 年内第几天 → 模 7」这条链抽象出来，配合前缀和即可 $O(1)$ 解决。
