## 题意简述

有 $N$ 位同学报名参加比赛，老师要给他们排座位。请输出所有可能的座次方案，每行一种，共 $N!$ 行。

每种方案中的人名之间用空格分隔，方案之间的顺序要求为：**按人名报名（输入）的先后顺序排列**，即先用输入顺序靠前的同学，等价于对下标 $1..N$ 做字典序全排列。

- 输入：第一行 $N$（$N \le 10$）；接下来 $N$ 行，每行一个人名。
- 输出：每行一种排列，按字典序（`1,2,3 → 1,3,2 → 2,1,3 → …`）输出。

样例输入：

```text
3
xiaowang
xiaoA
xiaoli
```

样例输出：

```text
xiaowang xiaoA xiaoli
xiaowang xiaoli xiaoA
xiaoA xiaowang xiaoli
xiaoA xiaoli xiaowang
xiaoli xiaowang xiaoA
xiaoli xiaoA xiaowang
```

## 思路分析

本质是**输出 $1..N$ 的全排列**，只是把数字换成了人名。核心是保证输出顺序为字典序，这样才和样例一致。

两种等价写法：

1. **回溯（DFS）**：按位置 `dep` 从 $0$ 到 $N-1$ 依次填人。每一层都从下标 $0$ 开始枚举未使用过的人，选一个填入当前位置、标记使用、递归下一层、再撤销标记。因为每层都是从小编号枚举，天然按字典序生成。
2. **`next_permutation`**：先把下标数组初始化为 `1,2,…,N`（升序），循环调用 `std::next_permutation` 并输出对应人名，直到返回 `false`。

回溯法的结构更直观，也更适合后面做「带限制条件的排列」（如相邻不能是谁），所以下面用回溯实现。

关于数组含义：

- `name[i]`：第 $i$ 个报名的人名（下标从 $0$ 开始）；
- `cur`：当前已经排好的座次，存的是人的下标，而不是名字；
- `used[i]`：第 $i$ 个人是否已经坐好。

存下标而不是名字的好处是：题目要求按「输入顺序」排序，而下标大小正好代表输入顺序，直接用下标比较/枚举即可。

## 复杂度

- 时间：$O(N! \cdot N)$。共有 $N!$ 种排列，每种输出需 $O(N)$；$N \le 10$ 时约 $3.6 \times 10^7$ 次基本操作，在 1 s 内可通过。
- 空间：$O(N)$，递归深度与 `cur`、`used` 均不超过 $N$（不计输出）。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<string> name;    // 按报名顺序存人名
vector<int> cur;        // 当前排列，存人的下标
vector<bool> used;      // 该人是否已经入座

void dfs(int dep) {
    if (dep == n) {                     // 排满 n 个人，输出一种方案
        for (int i = 0; i < n; ++i) {
            if (i) cout << ' ';
            cout << name[cur[i]];
        }
        cout << '\n';
        return;
    }
    // 每层都从下标 0 开始枚举，保证输出为字典序
    for (int i = 0; i < n; ++i) {
        if (used[i]) continue;
        used[i] = true;
        cur.push_back(i);
        dfs(dep + 1);
        cur.pop_back();                 // 回溯：撤销选择
        used[i] = false;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    name.resize(n);
    for (int i = 0; i < n; ++i) cin >> name[i];

    used.assign(n, false);
    dfs(0);
    return 0;
}
```

## 易错点 / 总结

- **顺序要求**：题目要求按报名顺序排列，因此必须枚举**下标** `0..n-1`；若先把人名按字典序 `sort` 再排列，输出顺序就会与样例不符（`xiaoA` 会排到最前面）。
- **忘记回溯**：递归返回后必须 `cur.pop_back()` 并把 `used[i]` 复位，否则后续分支会漏解或重复。
- **行末空格**：人名之间用空格分隔，但行末不能多输出空格，样例已体现这一点，用 `if (i) cout << ' ';` 处理。
- **重复人名**：若输入中出现重名，按本题「人」而非「名字」区分，输出会出现内容相同的多行，这是符合题意的，不要额外去重。
- **输出量**：$N=10$ 时输出约 360 万行，`cout` 需关闭同步（`ios::sync_with_stdio(false)`）以避免超时。
- **本题收获**：全排列是回溯的入门模型。掌握「选择 → 递归 → 撤销」的框架后，可以自然扩展到组合、子集、带剪枝的搜索等题型。
