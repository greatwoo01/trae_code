## 题意简述

有 $N$ 位同学报名参加比赛，老师要给他们排座位。请输出所有可能的座次方案，每行一种，共 $N!$ 行。

每种方案中的人名之间用空格分隔，方案之间的顺序要求为：**按人名报名（输入）的先后顺序排列**，即先用输入顺序靠前的同学，等价于对下标 $1..N$ 做字典序全排列。

- 输入：第一行 $N$（$N \le 10$）；接下来 $N$ 行，每行一个人名。
- 输出：每行一种排列，按字典序（`1,2,3 → 1,3,2 → 2,1,3 → …`）输出。

样例输入：

```text
3
xiaowang
xiaoA
xiaoli
```

样例输出：

```text
xiaowang xiaoA xiaoli
xiaowang xiaoli xiaoA
xiaoA xiaowang xiaoli
xiaoA xiaoli xiaowang
xiaoli xiaowang xiaoA
xiaoli xiaoA xiaowang
```

## 思路分析

本质是**输出 $1..N$ 的全排列**，只是把数字换成了人名。核心是保证输出顺序为字典序，这样才和样例一致。

两种等价写法：

1. **回溯（DFS）**：按位置 `dep` 从 $0$ 到 $N-1$ 依次填人。每一层都从下标 $0$ 开始枚举未使用过的人，选一个填入当前位置、标记使用、递归下一层、再撤销标记。因为每层都是从小编号枚举，天然按字典序生成。
2. **`next_permutation`**：先把下标数组初始化为 `1,2,…,N`（升序），循环调用 `std::next_permutation` 并输出对应人名，直到返回 `false`。

回溯法的结构更直观，也更适合后面做「带限制条件的排列」（如相邻不能是谁），所以下面用回溯实现。

关于数组含义：

- `name[i]`：第 $i$ 个报名的人名（下标从 $0$ 开始）；
- `cur`：当前已经排好的座次，存的是人的下标，而不是名字；
- `used[i]`：第 $i$ 个人是否已经坐好。

存下标而不是名字的好处是：题目要求按「输入顺序」排序，而下标大小正好代表输入顺序，直接用下标比较/枚举即可。

## 复杂度

- 时间：$O(N! \cdot N)$。共有 $N!$ 种排列，每种输出需 $O(N)$；$N \le 10$ 时约 $3.6 \times 10^7$ 次基本操作，在 1 s 内可通过。
- 空间：$O(N)$，递归深度与 `cur`、`used` 均不超过 $N$（不计输出）。

## 方法一：回溯（DFS）

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<string> name;    // 按报名顺序存人名
vector<int> cur;        // 当前排列，存人的下标
vector<bool> used;      // 该人是否已经入座

void dfs(int dep) {
    if (dep == n) {                     // 排满 n 个人，输出一种方案
        for (int i = 0; i < n; ++i) {
            if (i) cout << ' ';
            cout << name[cur[i]];
        }
        cout << '\n';
        return;
    }
    // 每层都从下标 0 开始枚举，保证输出为字典序
    for (int i = 0; i < n; ++i) {
        if (used[i]) continue;
        used[i] = true;
        cur.push_back(i);
        dfs(dep + 1);
        cur.pop_back();                 // 回溯：撤销选择
        used[i] = false;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    name.resize(n);
    for (int i = 0; i < n; ++i) cin >> name[i];

    used.assign(n, false);
    dfs(0);
    return 0;
}
```

## 方法二：next_permutation

既然本质是「按字典序输出全排列」，可以直接用 STL 的 `std::next_permutation`，无需手写回溯：

1. 用数组 `p = {0, 1, …, n-1}` 表示一种座次，`p[i]` 是坐在第 `i` 个位置的人的下标；
2. 初始时 `p` 为升序，正好对应字典序最小的方案；
3. 先输出当前方案，再调用 `next_permutation` 求下一个排列，返回 `false` 说明已到最后一个，循环结束。

`next_permutation` 内部同样是从右往左找「第一个可增大的位置」并交换，等价于字典序枚举，因此输出顺序与回溯法完全一致。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<string> name(n);
    for (auto &s : name) cin >> s;

    vector<int> p(n);
    iota(p.begin(), p.end(), 0);        // p = {0,1,...,n-1}，对应报名顺序

    do {
        for (int i = 0; i < n; ++i) {
            if (i) cout << ' ';
            cout << name[p[i]];
        }
        cout << '\n';
    } while (next_permutation(p.begin(), p.end()));

    return 0;
}
```

两种方法对比：

| 方法 | 优点 | 注意点 |
| --- | --- | --- |
| 回溯 DFS | 框架通用，易加限制条件（如相邻不能是谁） | 需手动维护 `used` 与回溯 |
| `next_permutation` | 代码短，不易写错 | 初始序列必须升序；只适用于「按字典序全排列」 |

复杂度相同：时间 $O(N! \cdot N)$，空间 $O(N)$。

### 实测效率对比

取 $N=10$（共 $3\,628\,800$ 种排列），使用 `g++ -O2` 编译，各跑 3 次取大致范围：

| 场景 | 回溯 DFS | `next_permutation` |
| --- | --- | --- |
| 只生成排列、不输出 | 约 0.15 s | 约 0.037 s |
| 输出到 `/dev/null`（含格式化） | 约 1.40–1.48 s | 约 1.30–1.37 s |

- **纯枚举阶段，`next_permutation` 约快 4 倍**。DFS 除了 $N!$ 个叶子，还要访问约 $e \cdot N!$ 个内部节点，每层都有函数调用、`push_back/pop_back` 与 `used` 置位/复位；而 `next_permutation` 是紧循环，均摊每次只涉及末尾两三个元素，且无递归开销。
- **加上输出后差距缩小到 10% 以内**。$N=10$ 时要打印约 360 万行，I/O 与格式化成为瓶颈，算法本身的常数差异被掩盖。
- 理论复杂度两者一致：DFS 每个叶子输出 $O(N)$；`next_permutation` 单次最坏 $O(N)$，均摊接近 $O(1)$。

选择建议：本题只是按字典序输出全排列，两者都能在 1 s 内通过，`next_permutation` 更快也更短；若后续要加限制条件（如某两人不能相邻、需要剪枝），应使用回溯 DFS——`next_permutation` 无法剪枝，只能全枚举后再过滤，反而可能更慢。

## 易错点 / 总结

- **顺序要求**：题目要求按报名顺序排列，因此必须枚举**下标** `0..n-1`；若先把人名按字典序 `sort` 再排列，输出顺序就会与样例不符（`xiaoA` 会排到最前面）。
- **忘记回溯**：递归返回后必须 `cur.pop_back()` 并把 `used[i]` 复位，否则后续分支会漏解或重复。
- **行末空格**：人名之间用空格分隔，但行末不能多输出空格，样例已体现这一点，用 `if (i) cout << ' ';` 处理。
- **重复人名**：若输入中出现重名，按本题「人」而非「名字」区分，输出会出现内容相同的多行，这是符合题意的，不要额外去重。
- **输出量**：$N=10$ 时输出约 360 万行，`cout` 需关闭同步（`ios::sync_with_stdio(false)`）以避免超时。
- **本题收获**：全排列是回溯的入门模型。掌握「选择 → 递归 → 撤销」的框架后，可以自然扩展到组合、子集、带剪枝的搜索等题型。
